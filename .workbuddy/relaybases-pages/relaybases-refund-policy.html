退款与取消政策

生效日期：2026 年 7 月 30 日

译文仅为方便理解而提供。如译文与英文版本存在冲突，以英文版本为准。

本政策适用于由 RelayBases Inc. 通过 RelayBases 提供的预付 API Credits 和按量计费 API 服务。API Credits（简称"Credits"）在账户内使用专用符号 Ɍ 显示。

服务交付

RelayBases 提供数字化 API 服务，不涉及实体商品、运输或退货。付款确认后，结账页所示数量的付费 Credits 通常会自动记入对应账户，并可立即使用。

Credits 仅可用于符合条件的 RelayBases 服务。Ɍ 仅表示记入账户或因 API 用量而扣减的 Credits，不是 USD 或其他货币、电子货币、加密货币、银行存款或可转让资产。Credits 不能转让、交易、提现或兑换现金，但本政策明确规定或适用法律要求的退款除外；获批退款仍以原订单的实际付款币种和金额为依据。

可退款情形

你可以申请退还符合条件的未使用付费 Credits，RelayBases 不设置固定申请期限。对于 Credits 充值，最多退还该笔购买中经系统账单及用量记录核实的未使用付费 Credits。

退款金额不会超过该笔交易的实际支付金额；退款处理时，相应的付费 Credits 将从账户中扣除。

经核实存在同一订单重复扣款、实际扣款与付款页面不一致、付款成功但因 RelayBases 系统错误未交付且无法补发 Credits、API 计量或计费错误，或适用法律要求退款的其他情形时，将单独处理，不以未使用 Credits 的普通退款条件为限。

不可退款情形

除适用法律另有要求外，已用于 API 请求或其他数字服务的 Credits、免费或赠送或试用或推广或奖励 Credits，以及已经退款或撤销或拒付的交易部分，均不予退款。

API 请求已正常处理并产生有效用量后，仅因对模型输出的内容、风格、准确性、速度或结果不满意，不能作为退款理由。因用户未妥善保管 API Key、账户凭据或客户端配置而产生的用量通常也不可退款。

如果你认为账户或 API Key 被盗用，请立即撤销相关 Key、保护账户并联系我们。我们会调查异常用量，但调查并不保证已经产生的有效上游使用费用可以退款。

服务故障与计费错误

未产生费用的失败请求不涉及退款。如果 RelayBases 的技术故障导致错误扣费，我们将在核实后恢复相应 Credits，或退还对应款项。

上游模型可能出现临时不可用、限流、内容过滤、响应差异或延迟。只要未发生错误计费，这些情况本身不产生现金退款；如果你认为用量记录有误，可以申请账单复核。

取消与 API 请求

付费 Credits 会即时交付，因此已完成的 Credits 购买不能直接取消，但符合上述条件时仍可申请退款。

关闭页面、中断客户端或网络断开，不一定会取消已经提交给上游处理的 API 请求；最终费用以 RelayBases 的请求及计量记录为准。

如何申请退款

请使用账户注册邮箱发送邮件至 contact@relaybases.com，并提供 RelayBases 用户 ID 或注册邮箱、订单号或付款标识、付款日期、金额和币种、退款原因，以及相关错误信息或请求时间。

请勿发送完整 API Key、银行卡号、验证码或密码。我们通常会在 3 个工作日内审核申请或联系你补充信息；退款获批后，我们将在 5 个工作日内发起退款。

退款方式与到账时间

退款将退回原付款方式，不能改付至其他银行卡、账户或数字钱包。我们发起退款后，款项通常会在约 5–10 个工作日内显示，实际时间取决于银行、发卡机构及支付方式。

RelayBases 不设置固定申请期限；但支付服务商或原付款方式可能对较早交易的退款存在技术或支付网络限制。如果原付款方式已无法接收退款，请联系我们，我们会审核可行且合规的处理方案。

退款按照原交易币种处理。因汇率变化、发卡行费用或银行换汇造成的差额不由 RelayBases 控制。

账单异议

如果你发现未识别扣款、重复扣款或用量异常，请尽快联系我们，以便我们检查付款和 API 使用记录。联系我们不会限制你依法向发卡机构提出异议的权利。

法定权利

本政策不排除或限制适用法律规定的、不得通过合同放弃的消费者权利。如本政策与强制性适用法律冲突，以该法律为准。

政策更新

我们可能根据服务、支付方式或法律要求更新本政策。新版本会在本页面公布并注明新的生效日期；除适用法律另有要求外，已经完成的交易通常适用购买时展示的政策版本。
