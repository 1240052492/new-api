关于 RelayBases

RelayBases Inc. 通过开发者熟悉的接口，为受支持的 AI 模型提供接入基础设施。我们专注于接入层——文档化端点、账户控制、用量可见性与实用工具，而不自行开发基础模型。

我们提供什么

将模型接入与日常使用所需的账户控制整合在同一项服务中。

兼容的 API 接入

通过 Claude 原生、OpenAI 兼容与 Gemini 路由，以文档化方式调用受支持模型，无需为每种工作流采用一套不同接口。

密钥与账户控制

在同一控制台管理 API 密钥、可用路由与账户设置，并通过文档完成常见接入流程。

用量与 API Credits

请求记录与 Credits 消耗在控制台中保持可见，便于用户了解账户的实际使用情况。

无限画布

无限画布是面向提示词与媒体工作流的可视化工作台，与直接 API 接入配合使用。

RelayBases 如何工作

RelayBases 位于应用与开发者选定的受支持模型路由之间，使接入过程保持明确且可查看。

  1. 选择接口

    查阅使用文档，并根据目标模型与工作流选择兼容端点或原生端点。

  2. 连接应用

    创建 API 密钥，按照文档中的请求格式，从你的应用或工具发起请求。

  3. 查看活动

    接入运行后，可在控制台查看请求记录与 Credits 用量，并通过服务状态页了解当前运行情况。

运营原则

我们以几项务实约束指导产品界面与政策的制定。

熟悉的接口

在能够减少接入工作的地方采用成熟 API 模式；行为无法完全一致时，明确记录重要差异。

用量可见

提供实用的账户与请求信息，让用户能够核查使用情况，而不是面对不可见的黑箱。

负责任的接入

明确可接受使用边界，并提供内容安全、举报与违规处置相关的政策依据。
