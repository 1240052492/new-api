API Key 与安全

API Key 属于访问凭据。请勿将其发布到公开代码仓库、客户端应用、截图、日志、提示词，或你不信任的第三方工具中。建议使用环境变量、密钥管理器、密钥轮换和最小权限实践。

如果密钥泄露，你应立即撤销或轮换。我们在检测到滥用、异常流量、支付风险或安全风险时，可能会限速、暂停或撤销相关密钥。

客户内容

"客户内容"指你发送到服务的提示词、消息、文件、图片、代码、元数据和其他材料，以及服务返回的输出。在你与 RelayBases 之间，你保留对客户内容已有的权利。

你需要对输入内容、输出内容的使用方式，以及使用场景所需的权利或授权负责。AI 输出可能不准确、不完整、不安全，也可能与其他用户获得的输出相似。

RelayBases 会为了提供、保护、排查和支持服务而处理客户内容。我们不主张拥有你的 API 输入或输出。我们的隐私政策说明了我们会收集、路由、存储和披露哪些数据。
