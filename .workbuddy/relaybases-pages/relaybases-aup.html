AI 可接受使用政策

最后更新：2026 年 8 月 2 日

译文仅为方便理解而提供。如译文与英文版本存在冲突，以英文版本为准。

RelayBases Inc.（以下简称"RelayBases"或"我们"）提供 API 接入与模型路由服务。本 AI 可接受使用政策（"本政策"）适用于通过我们的网站、API 网关、模型路由和无限画布提交、生成、编辑、存储、发布或传播内容的所有用户。本政策是服务条款的补充。

1. 适用范围

本政策适用于提示词和其他用户输入，文本、代码、图片、音频和视频，上传的参考文件，模型输出，API 元数据，以及通过 RelayBases 或上游模型生成、转换、自动化或传播禁止内容的尝试。客户需要对其输入、输出、下游应用和最终用户负责。

2. 禁止内容与行为

禁止利用 RelayBases 生成、编辑、请求、上传、存储或传播以下六类内容：

  1. 色情或 NSFW 内容：色情制品、露骨性内容、性服务、性化裸露或未经同意的私密影像。
  2. 暴力或血腥内容：血腥伤害、酷刑、肢解、美化现实暴力，或意图协助暴力违法行为的指导。
  3. 仇恨言论：基于受保护特征攻击、非人化、威胁他人或鼓励歧视的内容。
  4. 儿童不安全内容与 CSAM：任何未成年人性化描绘、儿童性虐待材料、诱骗、剥削或协助伤害儿童的内容。
  5. 深度伪造或冒充他人：欺骗性或未经同意地冒充真实个人、合成私密内容、身份欺诈，或将误导性媒体冒充真实内容。
  6. 侵犯版权或商标：违法复制、仿冒、盗用或侵犯版权、商标、肖像权、隐私权或其他知识产权的内容。

零容忍内容

我们对 CSAM 或涉及未成年人的性内容、恐怖主义或暴力极端主义支持、大规模杀伤性武器制造指导、煽动种族灭绝或大规模暴力，以及针对真实个人的未经同意私密深度伪造实行零容忍。我们可以立即限制访问、保全相关记录，并在法律要求或为保护安全所必要时向主管机关或儿童安全组织报告涉嫌违法行为。举报时请勿发送或附加疑似 CSAM。

其他禁止用途

同时禁止将服务用于欺诈、网络钓鱼、恶意软件、凭据窃取、垃圾信息、违法商品或服务、绕过安全机制、越狱提示词、侵犯隐私、定向骚扰、鼓励危险自残、实质性误导政治内容，或未经适当人工监督的医疗、法律、金融、就业、住房、保险及其他高影响决策。法律要求披露或不披露会导致欺骗时，不得隐瞒内容由 AI 生成。

3. 内容审核机制

RelayBases 采用自动筛查、上游服务商安全机制、人工复核与定期政策检查相结合的分层流程。由于 RelayBases 会路由到多个第三方模型，具体安全分类器会因路由和内容类型而不同。

  • 网关自动筛查：RelayBases Prompt Filter 是我们的网关策略引擎，会对支持路由的提示词输入和输出流进行风险模式扫描，并监控异常 API 使用行为。被标记的事件可记录并优先进入复核。
  • 服务商安全机制：请求与输出同时受所选上游模型服务商的安全系统和使用政策约束。服务商控制可能在内容返回前拒绝、转换或拦截相关内容。
  • 人工复核：自动信号、服务商通知、支付或安全风险、用户举报识别出的活动，可能由 RelayBases 人员复核。我们仅使用完成复核所合理需要的信息。
  • 定期检查：我们至少每月复核被标记事件趋势、滥用模式、处置结果与审核有效性，并在风险、模型或法律要求发生变化时调整控制措施。

自动系统并不完美。未被自动拦截的请求仍可能违反本政策，我们可在复核后采取措施。为防止伤害或遵守上游规则，我们也可以限制相关路由、模型、密钥、账户或输出。

4. 底层 AI 模型与服务商披露

RelayBases 不训练通过服务提供的基础模型。我们提供对具有服务商安全防护机制的第三方模型的接入与路由。可用模型会因账户、地区、路由和上游容量而调整，控制台模型目录是当前可用性与价格的准确信息来源。目前公开记录的模型系列包括：

  • 文本与代码：文本生成、推理、编程和工具调用线路。
  • 图片生成与编辑：同步和异步图片线路。
  • 视频生成与编辑：同步和异步视频线路。

模型名称与公司名称仅用于说明兼容的第三方服务。RelayBases 独立运营，并不主张获得相关服务商背书。

5. 用户举报渠道

如发现疑似违反本政策的内容、儿童安全风险、极端主义内容、冒充行为、未经同意的深度伪造、欺诈或知识产权侵权，请发送邮件至 contact@relaybases.com，主题填写 AIGC Safety Report。

请提供相关账户标识、请求 ID、URL 或路由、大致时间、简要说明和不包含敏感信息的证据。请勿发送完整 API Key、密码或疑似 CSAM。除调查、保护安全或遵守法律确有必要外，我们会对举报人身份保密。所有举报均会被客观评估；故意虚假或恶意举报也可能导致限制。

6. 审核与响应目标

我们按严重程度对举报进行分级。以下时效为运营目标而非保证；复杂案件或法律请求可能需要更多时间，我们会在可行时提供进展说明。

级别示例初步响应目标处理完成目标
L1 — 严重儿童安全、恐怖主义、迫在眉睫的严重伤害2 小时内24 小时内
L2 — 高风险严重禁止内容、可信的冒充或欺诈1 个工作日内3 个工作日内
L3 — 中风险确认的一般滥用或重复的较低风险违规3 个工作日内7 个工作日内
L4 — 较低风险需要澄清的轻微或存在歧义的违规5 个工作日内15 个工作日内

常规处理流程为：确认收件、严重程度分级、自动信号与人工复核、作出处置决定、执行处置，并在法律允许且适当时通知举报人和受影响客户。

7. 违规处置机制

我们会根据严重程度、背景、重复次数、主观意图、法律义务与潜在伤害，采取一项或多项措施：

  1. 书面警告或要求整改。
  2. 移除平台可控内容，或停用相关输出、路由或共享资产的访问。
  3. 降低速率限制、撤销 API Key，或限制特定模型与功能。
  4. 在复核期间临时暂停账户。
  5. 对严重、重复或故意违规永久终止账户。
  6. 保全证据、通知上游服务商，并向主管机关或儿童安全组织报告涉嫌违法行为。

L1 违规可能导致立即暂停或永久封禁；L2 违规通常会被优先复核，并采取临时限制或暂停；L3 与 L4 可先从警告、移除内容或限制功能开始，但重复违规会升级处置。规避处置（包括创建替代账户）可能导致永久封禁。

8. 申诉与政策变更

客户可在收到处置通知后 15 日内发送邮件至 contact@relaybases.com，主题填写 AIGC Policy Appeal。请提供账户标识、决定日期和要求重新考虑的理由。申诉由未参与初次决定的人员复核，我们争取在 10 个工作日内完成。

我们可能根据模型、风险、法律或服务商要求更新本政策。重大变更会更新"最后更新"日期，也可能通过网站或控制台通知。

RelayBases 是 API 基础设施提供商，不是上述第三方基础模型的开发者。客户还必须遵守适用的上游服务商政策和所在法域的法律。
