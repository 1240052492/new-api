常见问题

产品定位、计费、兼容性、数据与团队服务等高频问题。

产品与能力

智算星球是什么？和官方 API 有什么区别？

智算星球是独立的多模型 API 聚合网关，不是 OpenAI、Anthropic 或其他模型厂商的官方订阅。你可以在平台创建 API Key，把常用模型接入已经在用的开发工具，一个账户管理全部调用。

目前支持哪些模型和能力？

支持 GPT、Claude、Gemini、DeepSeek、Qwen、Kimi 等模型系列，同时支持图像生成、视频合成、音频与向量嵌入模型。可用模型、价格与具体能力以控制台实时展示为准。

可以接入哪些客户端和开发工具？

任何支持 OpenAI API 或自定义 Base URL 的软件和框架均可接入，包括 Claude Code、Codex、Cursor、Cherry Studio、LobeChat、LangChain、Dify 等。详见客户端接入。

计费与账户

如何计费？可以先试用再充值吗？

按 Token 用量计费，注册后即可使用赠送额度完成接入与小规模测试；正式使用时在控制台在线充值，余额实时扣减。规则详见定价说明。

失败请求会计费吗？

因上游或平台原因导致的失败请求不计费；已成功转发但因客户端原因中断的请求，按实际产生的 Token 用量结算。

如何控制消费上限？

可为每个 API 令牌单独设置额度上限与过期时间；账户余额低于阈值时可在控制台开启预警提醒。

需要发票、对公转账或团队接入怎么办？

企业用户可支持对公转账、合同签订、发票与采购材料。请通过页脚邮箱联系商务，或在控制台提交工单说明需求。

数据与安全

我的请求数据会被用于训练吗？

不会。平台不使用你的请求数据训练、微调或蒸馏模型。数据仅在完成请求、保障服务与必要排障所需的范围内临时处理，详见隐私政策。

API Key 泄露了怎么办？

请立即到控制台「令牌」页面删除或重置该令牌，并检查用量日志确认异常消费；如需协助请联系客服。

接口报 401 / 429 应该如何排查？

401 通常是密钥错误、过期或被删除，请重新创建令牌；429 通常是触发限流或余额不足，请按 Retry-After 重试并确认余额。更多状态码见接口文档。
