客户端接入

任何支持 OpenAI API 或自定义 Base URL 的客户端均可接入智算星球。以下为主流工具的配置方法。

通用配置

配置项值
Base URL（OpenAI 兼容）https://www.aiplantform.site/v1
API Key控制台「令牌」页创建，形如 sk-xxx

Claude Code

Claude Code 使用 Anthropic 协议，通过环境变量替换接入地址与密钥：

export ANTHROPIC_BASE_URL=https://www.aiplantform.site
export ANTHROPIC_AUTH_TOKEN=sk-你的智算星球令牌
export ANTHROPIC_MODEL=claude-sonnet-5

# Windows PowerShell
$env:ANTHROPIC_BASE_URL = "https://www.aiplantform.site"
$env:ANTHROPIC_AUTH_TOKEN = "sk-你的智算星球令牌"

配置后启动 claude 即可正常使用，用量将计入你的智算星球账户。

Codex CLI

编辑 ~/.codex/config.toml（Windows 为 %USERPROFILE%\.codex\config.toml）：

model = "gpt-5.6"
model_provider = "zhisuan"

[model_providers.zhisuan]
name = "智算星球"
base_url = "https://www.aiplantform.site/v1"
env_key = "ZHISUAN_API_KEY"

并在环境变量中设置 ZHISUAN_API_KEY=sk-你的令牌。

Cursor

  1. 打开 Settings → Models → OpenAI API Key；
  2. 填入你的智算星球 API Key，勾选 Override Base URL；
  3. Base URL 填 https://www.aiplantform.site/v1，保存后校验密钥；
  4. 在模型列表中添加你需要的模型名称（如 gpt-5.6）。

Cherry Studio / LobeChat 等 GUI 客户端

  1. 在「设置 → 模型服务」中新增自定义服务商（OpenAI 兼容类型）；
  2. API 地址填 https://www.aiplantform.site/v1，密钥填你的 sk-令牌；
  3. 手动添加模型名称后即可对话。

OpenAI SDK（Python / Node.js）

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的令牌",
    base_url="https://www.aiplantform.site/v1",
)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-你的令牌",
  baseURL: "https://www.aiplantform.site/v1",
});
其他工具（LangChain、Dify、n8n、沉浸式翻译等）凡支持自定义 OpenAI 兼容地址的，均按「Base URL + API Key」方式接入即可。遇到问题请查阅常见问题或提交工单。
