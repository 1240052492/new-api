接口文档

OpenAI 兼容接口参考。所有接口均需在请求头携带 Authorization: Bearer YOUR_API_KEY。

认证方式

在控制台创建的 API Key 以 Bearer Token 方式使用：

Authorization: Bearer sk-xxxxxxxxxxxxxxxx
请勿将 API Key 暴露在浏览器端代码或公开仓库中。可为每个令牌设置额度上限与过期时间以控制风险。

Chat Completions — 对话补全

POST /v1/chat/completions，支持流式（stream: true）与非流式两种模式，请求体与 OpenAI 官方一致。

请求参数（常用）

参数类型必填说明
modelstring是模型名称，如 gpt-5.6、claude-sonnet-5
messagesarray是对话消息数组，包含 role 与 content
streamboolean否是否流式返回，默认 false
temperaturenumber否采样温度，0-2，默认 1
max_tokensinteger否最大输出 Token 数

响应示例

{
  "id": "chatcmpl-xxxx",
  "object": "chat.completion",
  "model": "gpt-5.6-mini",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "你好！我是……" },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 48,
    "total_tokens": 60
  }
}

List Models — 模型列表

GET /v1/models，返回当前账户可用的全部模型。

curl https://www.aiplantform.site/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

Images Generations — 图像生成

POST /v1/images/generations，异步任务接口。常用参数：

参数类型必填说明
modelstring是图像模型，如 gpt-image-2
promptstring是图像描述提示词
sizestring否画面比例，如 1:1、16:9
ninteger否生成数量，默认 1

提交后返回任务 ID，通过 GET /v1/images/generations/{task_id} 查询状态与结果。视频模型使用 /v1/videos/generations，参数与查询方式类似。

错误码

状态码含义处理建议
400请求参数错误检查请求体格式与参数取值
401认证失败检查 API Key 是否正确、是否已过期
403无权访问确认账户分组是否允许使用该模型
429请求过于频繁 / 余额不足按 Retry-After 重试；确认余额与令牌额度
500服务内部错误稍后重试；持续失败请联系客服
需要更多帮助？请前往常见问题，或通过控制台提交工单。
