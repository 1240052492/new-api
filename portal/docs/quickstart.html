快速开始

使用智算星球调用文本、图像、视频与音频模型，五分钟完成第一次调用。

平台提供 OpenAI 兼容接口，Base URL 为 https://www.aiplantform.site/v1。文中示例均可直接替换密钥后使用。

第一步：获取 API 密钥

  1. 注册并登录后，进入控制台 「令牌」管理页面；
  2. 创建一个新的 API Key，可为其设置额度上限与过期时间；
  3. 立即安全保存密钥，密钥仅在创建时完整显示一次。

第二步：选择模型

类型推荐入门模型说明
文本gpt-5.6-mini性能与成本均衡，适合通用对话与 Agent 工作流
图像gpt-image-2支持文生图与参考图编辑，按次计费
视频seedance-2支持文生视频与图生视频，按秒计费

完整可用模型以控制台模型广场与模型列表页为准。

第三步：发送请求

文本生成

curl --request POST \
  --url https://www.aiplantform.site/v1/chat/completions \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.6-mini",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
  }'

Python（OpenAI SDK）

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://www.aiplantform.site/v1",
)

resp = client.chat.completions.create(
    model="gpt-5.6-mini",
    messages=[{"role": "user", "content": "你好，请介绍一下你自己"}],
)
print(resp.choices[0].message.content)

图像生成（异步任务）

curl --request POST \
  --url https://www.aiplantform.site/v1/images/generations \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-image-2",
    "prompt": "一只可爱的熊猫，电影感光线",
    "size": "1:1",
    "n": 1
  }'

第四步：查询异步任务

文本请求直接返回结果；图像与视频请求会返回任务 ID，使用对应查询接口获取结果：

curl https://www.aiplantform.site/v1/images/generations/YOUR_TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
收到 429 时请读取响应头 Retry-After 并按其指示重试，不要固定高频重试。
