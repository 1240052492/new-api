FAQ

开始之前，你可能想确认这些问题

智算星球和官方 API、订阅服务有什么区别？

智算星球是独立的多模型 API 聚合网关，不是任何模型厂商的官方订阅。你可以在平台创建 API Key，把常用模型接入已经在用的开发工具，一个账户、一张账单管理全部模型调用。

支持哪些模型和能力？

当前支持 GPT、Claude、Gemini、DeepSeek、Qwen、Kimi 等多个模型系列，同时支持图像生成、视频合成与音频模型。可用模型、价格与具体能力以控制台实时展示为准。

如何计费？可以先试用再充值吗？

平台按 Token 用量计费，注册后即可使用赠送额度完成接入与小规模测试；正式使用时在控制台在线充值，余额实时扣减，明细可查。

可以接入哪些客户端和开发工具？

任何支持 OpenAI API 或自定义 Base URL 的软件和框架均可接入，包括 Claude Code、Codex、Cursor、Cherry Studio、LobeChat、LangChain、Dify 等。接入方法见客户端接入文档。

我的请求数据会被如何处理？

平台不会将你的请求数据用于训练或蒸馏模型。数据仅在完成请求、保障服务与必要排障所需的范围内临时处理，详见隐私政策。
