关于智算星球

智算星球是一个面向开发者与企业的多模型 API 聚合网关。一个 API Key 即可调用 GPT、Claude、Gemini、DeepSeek 等主流模型，OpenAI 兼容协议，改一行 Base URL 即可使用，统一鉴权、统一计费、故障自动切换。

  • 统一入口：200+ 模型一站接入，密钥、用量与账单集中管理；
  • 透明计费：按 Token 用量计费，倍率公开，明细实时可查；
  • 稳定可靠：多上游智能路由与故障切换，国内网络低延迟直连；
  • 数据安全：请求数据不用于模型训练，详见隐私政策。
