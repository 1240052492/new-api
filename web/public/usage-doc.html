使用教程

快速开始

智算星球 提供 OpenAI、Anthropic、Gemini 兼容的 API 接入。本页说明如何购买 API Credits、创建 API 密钥，并在 Claude Code、Codex CLI 等客户端中完成配置。

打开控制台 购买 Credits API 密钥

API Credits 与 API 密钥

首次使用时，先准备可用的 API Credits，再按客户端用途创建 API 密钥。明确使用单一路线时，可为 Claude、OpenAI、Gemini、图像等分组分别创建密钥；需要跨多个可用分组自动匹配模型时，可使用 auto 分组。

计价单位

⚡ 表示 智算星球 API Credits

⚡ 是 API Credits 的展示单位。充值后，Credits 会记入账户，并在调用 API 时按模型价格、分组倍率和实际用量扣减；⚡ 不是 USD 或其他货币，也不是电子货币或加密货币。

余额与用量
余额、模型价格和用量费用使用 ⚡ 显示，例如 ⚡0.08。
实际付款
订单以 USD 计价；结账页和付款记录会显示实际收取的金额与币种。
退款
符合条件的未使用付费 Credits 可按退款政策退回原付款方式；⚡ 本身不可转让、交易或提现。
  1. 购买 Credits。打开 Credits 页面，确认“实际支付”和“到账 Credits”，选择金额并按页面提示完成支付。
  2. 打开 API 密钥页。从控制台左侧进入 API 密钥页面，确认已有密钥和分组。
  3. 创建密钥。填写名称，选择对应分组，设置过期时间和额度。完整密钥只在创建后显示一次。
  4. 配置客户端。把密钥写入环境变量或本地配置文件，不要提交到公开仓库，也不要出现在截图或日志里。

选择 API 地址

标准地址和美国直连地址使用相同的 API 密钥、模型名称、账户余额与计费规则，区别只在网络路径。一般情况下优先使用标准地址；长时间同步请求遇到 Cloudflare 代理超时时，再改用美国直连地址。

地址 Base URL 适用场景
标准 API https://www.aiplantform.site 经 Cloudflare 加速，网络兼容性更好，适合作为默认地址；长时间同步请求可能受到代理超时限制。
美国直连 API https://us.aiplantform.site 直连美国源站，不受 Cloudflare 代理超时限制，适合长时间同步请求；部分网络环境可能无法访问。
协议路径保持不变：Anthropic 原生协议使用上表中的域名，不添加 /v1；OpenAI 兼容协议在所选域名后添加 /v1。图片和视频任务仍使用媒体创作地址 https://aigc.aiplantform.site。

直连地址只绕过 Cloudflare 代理，不代表请求永远不会因客户端、源站、上游模型或网络中断而失败。若直连地址无法访问，请切回标准地址。

自动路由与故障转移

创建或编辑 API 密钥时选择 auto 分组，智算星球 会按照控制台显示的优先顺序，检查该密钥有权使用、支持当前模型且存在可用线路的分组，并选择第一个可用分组。

  1. 打开 API 密钥。进入控制台的“API 密钥”页面，创建新密钥或编辑现有密钥。
  2. 选择 auto。在“分组”中选择 auto。
  3. 确认分组顺序。推荐保留“继承全局 Auto 顺序”，自动跟随平台维护的完整顺序；也可为单个密钥选择候选分组并拖动排序。
  4. 开启跨分组重试。开启后，如果当前分组已经选中线路但调用失败，系统会继续按顺序尝试后续分组。
  5. 保存并照常调用。客户端的 Base URL、模型名和密钥使用方式均无需改变。
路由说明：如果某个候选分组不支持当前模型或没有可用线路，系统会直接检查下一个分组；“跨分组重试”控制的是已经选中线路但实际调用失败后，是否继续尝试后续分组。
计费说明：auto 没有独立倍率。每次请求按最终实际命中的分组倍率、模型价格和实际用量扣减 Credits；如果所有候选分组均无可用线路，请求仍会失败。

继承模式会使用平台当前维护的完整 Auto 顺序；自定义顺序保存为该密钥的独立配置，并始终受账户当前分组权限约束。现有密钥不会自动切换为 auto。

Claude Code

Claude Code 使用 Anthropic 原生协议，Base URL 不需要 /v1。建议为 Claude 单独创建一个 Claude 分组的 API 密钥。

Anthropic Base URL：https://www.aiplantform.site。建议通过 ANTHROPIC_AUTH_TOKEN 读取密钥，不要写进项目代码。

其他客户端

Cursor、Cline、Chatbox、Cherry Studio、Gemini CLI、Dify、N8N 等工具通常只需要 Base URL、模型名和 API 密钥。先确认客户端使用的是 Anthropic、OpenAI 兼容还是 Gemini 相关协议，再填对应端点。

用途 Base URL 密钥分组
Claude / Anthropic 原生协议 https://www.aiplantform.site Claude 或 Anthropic 相关分组
OpenAI 兼容协议 https://www.aiplantform.site/v1 OpenAI / GPT / Codex 相关分组
Gemini 模型 / Gemini CLI 按客户端使用的 Gemini 或 OpenAI 兼容地址填写 使用实时模型详情中显示的 Gemini 可用分组
图像生成 https://aigc.aiplantform.site media 分组；使用同步图片端点，具体模型和价格以实时目录为准
图片与视频任务 https://aigc.aiplantform.site media 分组；同步视频调用 /v1/video/generations，异步任务调用 /v1/videos，Seedance 视频调用 /v1/contents/generations/tasks

图片与视频任务接口

使用 media 分组创建的 API Key，并从上方实时目录选择当前可用模型。图片可使用同步生成或编辑端点；视频可使用同步生成端点，也可按任务工作流使用异步端点。

用途 方法 路径
同步生成图片 POST /v1/images/generations
同步编辑图片 POST /v1/images/edits
同步生成视频 POST /v1/video/generations
提交异步任务 POST /v1/videos
查询异步任务 GET /v1/videos/{task_id}
下载任务结果 GET /v1/videos/{task_id}/content
提交 Seedance 视频任务 POST /v1/contents/generations/tasks
查询 Seedance 视频任务 GET /v1/contents/generations/tasks/{task_id}

以上路径的 Base URL 均为 https://aigc.aiplantform.site；Seedance 的参数与价格见下方 Seedance 视频 小节。最终扣费以实时目录和控制台账单为准。

仅在任务状态为 completed 后读取内容。

任务没有立刻返回图片或视频

这是正常的。/v1/videos 是异步任务接口，提交成功后先返回 task_id，需要用查询接口轮询。状态为 queued、processing 或 in_progress 时继续等待；状态为 completed 时读取 video_url、image_url、url 或 result_urls。

同步和异步怎么选

同步图片使用 /v1/images/generations 或 /v1/images/edits，同步视频使用 /v1/video/generations，异步任务使用 /v1/videos。请从上方实时目录选择当前可用模型，并以目录和控制台账单为准。

参数错误或任务失败怎么处理

不同模型支持的媒体输入、图片数量、时长、比例和分辨率可能不同，请以实时模型详情为准。任务失败或被拒绝时以控制台账单为准；如出现异常扣费，请保留 task_id 并使用页面页脚中的支持链接提交核查。

提示模型或分组不可用

请确认 API Key 属于 media 分组，并确认请求地址是对应接口：同步图片使用 /v1/images/generations，同步视频使用 /v1/video/generations，异步任务使用 /v1/videos。不要把这些模型发到 /v1/chat/completions 或 /v1/responses。

Seedance 视频（官方任务协议）

豆包 Seedance 2.0、2.0 Fast、2.0 Mini 和 2.5 使用 Seedance 官方任务协议：提交任务后立即返回任务 ID，再轮询查询结果。请使用 media 分组创建的 API Key，Base URL 为 https://aigc.aiplantform.site。

用途 方法 路径
创建任务 POST /v1/contents/generations/tasks
查询任务 GET /v1/contents/generations/tasks/{task_id}

已经按 Seedance 官方任务协议接入的程序，只需把 Base URL 换成 https://aigc.aiplantform.site/v1，并使用 智算星球 API Key。

字段 类型 必填 说明
model string 是 上表中的模型 ID。
content array 是 至少包含一个非空 text 条目；可附加 image_url、video_url 和 audio_url，规则见下表。
resolution string 是 按模型填写上表支持的分辨率；填写模型不支持的值会被拒绝，不扣费。
duration integer 否 视频秒数。Seedance 2.0、2.0 Fast 和 2.0 Mini 支持 4–15 秒；Seedance 2.5 支持 4–30 秒；省略时默认 4 秒。
ratio string 否 画面比例，默认 16:9；支持 16:9、9:16、1:1、21:9、4:3、3:4。
seed integer 否 随机种子，原样传递给生成服务。
generate_audio boolean 否 是否生成音频，由上游模型能力决定。
watermark boolean 否 水印设置，由上游模型能力决定。
return_last_frame boolean 否 是否在上游支持时返回末帧。
priority integer 否 任务优先级，原样传递给生成服务。
execution_expires_after integer 否 任务执行有效期，单位及取值范围遵循上游协议。
tools array 否 模型工具配置，原样传递给生成服务。
safety_identifier string 否 调用方提供的安全标识。

参考素材

类型 role 规则
text — 必填，至少一个非空条目。
image_url reference_image first_frame last_frame 公网 URL 或 asset://… 素材引用；首帧、尾帧各最多一张，使用首尾帧时图片总数最多两张，且不能同时传参考视频。
video_url reference_video 公网 URL 或 asset://… 素材引用；携带后按“含参考视频”价格计费。
audio_url reference_audio 公网 URL 或 asset://… 素材引用。

返回处理

# OpenAI 兼容图片响应通常位于 data 数组：
# data[0].url             图片地址（若当前模型返回 URL）
# data[0].b64_json        base64 图片内容（若当前模型返回内联数据）
# data[0].revised_prompt  模型实际使用的提示词（若提供）

jq -r '.data[0].url // .data[0].b64_json // empty' response.json

返回的是 URL 还是 b64_json

返回格式取决于当前模型和请求参数；请同时处理 data[0].url 与 data[0].b64_json。如果返回 error 对象，请按其中的 message 排查；遇到 502、server_error 等临时错误可稍后重试。

提示模型或分组不可用

通常是 Key 不属于 media 分组，或请求发送到了通用文本端点。请重新创建 media 分组 Key，并确认 URL 是 https://aigc.aiplantform.site。

连接中断 / 超时（curl 56、schannel closed abruptly）

图片接口是同步返回，quality=high 的请求通常要等 1–3 分钟，更大尺寸更久。等待期间如果客户端或中间代理超时，就会出现 curl: (56) schannel: server closed abruptly 这类连接中断。请加大超时并自动重试，例如 --max-time 600 --retry 3 --retry-all-errors；首次联调建议先用 1024x1024 跑通，再按需提高尺寸。

Windows 下如何运行

PowerShell 里的 curl 是 Invoke-WebRequest 的别名，请改用 curl.exe，并把上面的命令写成单行（去掉行尾的 \）。Windows 自带没有 jq/base64，可先用 -o response.json 保存返回，再用 PowerShell 解码：powershell -Command "$j=Get-Content response.json | ConvertFrom-Json; [IO.File]::WriteAllBytes('out.png', [Convert]::FromBase64String($j.data[0].b64_json))"。

故障排查

安装失败或下载很慢

先确认网络能够访问官方安装源，并检查代理、防火墙和 DNS。Windows 用户可在管理员终端中重试。

命令未找到

确认 Node.js、npm 和全局安装目录已加入 PATH。macOS / Linux 可检查 npm config get prefix，Windows 需要重新打开 PowerShell 或 VS Code。

密钥无效或 401

确认密钥复制完整、没有多余空格，并且未被禁用或过期。完整密钥只在创建后显示一次，丢失后需要重新创建。

端点不匹配

Claude Code 使用所选域名本身，例如 https://www.aiplantform.site；OpenAI 兼容客户端需要添加 /v1，例如 https://www.aiplantform.site/v1。美国直连地址遵循相同规则。

长时间同步请求超时

标准地址经过 Cloudflare，长时间同步请求可能受到代理超时限制。可将同一客户端的域名改为 us.aiplantform.site，并保留原协议路径和 API 密钥；该直连地址在部分网络环境中可能无法访问。

环境变量没有生效

临时环境变量只对当前终端有效。写入 ~/.zshrc、~/.bashrc 或 Windows 用户环境变量后，需要重新打开终端和编辑器。

无法连接 API

先确认 Base URL 填写正确，再检查代理、防火墙和 DNS。macOS / Linux 可分别测试 curl -I https://www.aiplantform.site 和 curl -I https://us.aiplantform.site；Windows 可分别使用 Test-NetConnection www.aiplantform.site -Port 443 和 Test-NetConnection us.aiplantform.site -Port 443。

Credits 余额或分组不对

确认账户的 API Credits 余额充足，并确保密钥分组和模型类型一致。图像模型需要使用 media 分组和图像端点。

图像接口不通

图像生成不要使用通用 OpenAI 兼容端点，请使用 https://aigc.aiplantform.site，并确认密钥属于 media 分组。

Getting started

智算星球 provides OpenAI-, Anthropic-, and Gemini-compatible API access. This page covers purchasing API Credits, creating API keys, and configuring clients such as Claude Code and Codex CLI.

Open Console Buy Credits API Keys

API Credits and API keys

Start with available API Credits, then create API keys for each protocol or model group. Use separate Claude, OpenAI, Gemini, or image keys when you need a fixed route; use the auto group when one key should match models across multiple available groups.

Billing unit

⚡ represents 智算星球 API Credits

⚡ is the display unit for API Credits. After a top-up, Credits are added to your account and deducted as you use the APIs according to model prices, group multipliers, and actual usage. ⚡ is not USD or any other currency, electronic money, or cryptocurrency.

Balance and usage
Balances, model prices, and usage costs are displayed in ⚡, for example ⚡0.08.
What you pay
Orders are priced in USD. Checkout and payment records show the amount and currency charged.
Refunds
Eligible unused paid Credits may be returned to the original payment method under the Refund Policy. ⚡ itself cannot be transferred, traded, or withdrawn.
  1. Buy Credits. Open the Credits page, review “You pay” and “You receive,” choose an amount, then complete payment.
  2. Open API Keys. Go to the API Keys page from the console sidebar and review existing groups.
  3. Create a key. Enter a name, choose a group, and set quota or expiration. The full key is shown once.
  4. Use it in clients. Put the key in environment variables or config files, never in public repos, screenshots, or logs.

Choose an API endpoint

The standard and US direct endpoints use the same API keys, model names, account balance, and billing rules. Only the network path changes. Use the standard endpoint by default, then switch to the US direct endpoint when a long-running synchronous request encounters a Cloudflare proxy timeout.

Endpoint Base URL When to use it
Standard API https://www.aiplantform.site Cloudflare-accelerated with broader network compatibility. Recommended as the default; long-running synchronous requests may be subject to proxy timeouts.
US Direct API https://us.aiplantform.site Connects directly to the US origin without Cloudflare proxy timeouts. Recommended for long-running synchronous requests; it may be unreachable from some networks.
Protocol paths do not change: use the hostname as shown for the native Anthropic protocol, without /v1; append /v1 for OpenAI-compatible clients. Image and video tasks continue to use the dedicated endpoint https://aigc.aiplantform.site.

The direct endpoint bypasses only the Cloudflare proxy. Client, origin, upstream-model, or network failures can still interrupt a request. Switch back to the standard endpoint if the direct endpoint is not reachable.

Automatic routing and failover

When you create or edit an API key, select the auto group. 智算星球 checks the groups that the key may use, in the priority order shown in the console, and selects the first group that supports the requested model and has an available route.

  1. Open API Keys. Create a new key or edit an existing key in the console.
  2. Select auto. Choose auto under Group.
  3. Review the group order. Keeping Inherit global Auto order is recommended so the key follows the complete platform-managed order. You can also choose and reorder candidate groups for this key.
  4. Enable Cross-group retry. If a route in the selected group fails, 智算星球 can continue with later groups in order.
  5. Save and call the API normally. Your Base URL, model names, and key usage do not change.
Routing behavior: if a candidate group does not support the requested model or has no available route, 智算星球 checks the next group automatically. Cross-group retry controls whether it also continues after an already selected route fails during the request.
Billing: auto has no separate multiplier. Each request is charged using the multiplier of the group actually selected, the model price, and actual usage. The request can still fail if no candidate group has an available route.

Inheritance uses the complete Auto order currently maintained by the platform. A custom order is stored for that key and remains subject to the account's current group permissions. Existing keys are not changed to auto automatically.

When should I use sync or async?

Use /v1/images/generations or /v1/images/edits for synchronous images, /v1/video/generations for synchronous video, and /v1/videos for asynchronous tasks. Select a currently available model from the live catalog above; the catalog and console bill are authoritative.

What happens on invalid input or task failure?

Supported media inputs, image counts, durations, aspect ratios, and resolutions vary by model; use the live model details as the source of truth. For rejected or failed tasks, use the console bill as authoritative. If a charge looks incorrect, keep the task_id and use the support links in the page footer to request a review.

Model or group not available

How to read the task status

queued and processing mean the task is still waiting or generating, so keep polling. On succeeded, read content.video_url and usage.total_tokens. On failed, read error.message. The video URL comes from the upstream, so download and store it promptly.

How billing works

An estimated amount is reserved when the task is created. After success, the task settles on the usage.total_tokens returned upstream, with any difference refunded or charged. Failed or rejected tasks release the reservation. The console bill is authoritative.

Image generation and editing

Image generation and editing use the dedicated Base URL https://aigc.aiplantform.site. Use an API key created in the media group and select a currently available image model from the live catalog above. Supported parameters, response formats, and prices are defined by the model details and console bill.

Use JSON with /v1/images/generations for text-to-image generation. Use multipart/form-data with /v1/images/edits for image editing. Replace CURRENT_IMAGE_MODEL in the examples with an available model from the live catalog.

Generate an image

curl -sS --max-time 600 -X POST "https://aigc.aiplantform.site/v1/images/generations" \

    "quality": "high",
    "output_format": "png",

Read the response

# OpenAI-compatible image responses commonly use the data array:
# data[0].url             image URL when returned by the current model
# data[0].b64_json        inline base64 image data when returned
# data[0].revised_prompt  revised prompt when provided

jq -r '.data[0].url // .data[0].b64_json // empty' response.json

Does the response use a URL or b64_json?

The response format depends on the current model and request parameters; handle both data[0].url and data[0].b64_json. If you get an error object, follow its message; retry transient 502 or server_error responses later.

Model or group not available

This usually means the key is not in the media group, or the request was sent to a general text endpoint. Create a media-group key and confirm the URL is https://aigc.aiplantform.site.

Connection dropped / timeout (curl 56, schannel closed abruptly)

The image endpoints respond synchronously; a quality=high request typically takes 1–3 minutes, and larger sizes take longer. If the client or an intermediate proxy times out during the wait, you see errors like curl: (56) schannel: server closed abruptly. Raise the timeout and auto-retry, e.g. --max-time 600 --retry 3 --retry-all-errors, and start with 1024x1024 before scaling up.

Running on Windows

In PowerShell, curl is an alias for Invoke-WebRequest — use curl.exe and put the command on a single line (drop the trailing \). Windows has no built-in jq/base64, so save the response with -o response.json and decode it in PowerShell: powershell -Command "$j=Get-Content response.json | ConvertFrom-Json; [IO.File]::WriteAllBytes('out.png', [Convert]::FromBase64String($j.data[0].b64_json))".

Troubleshooting

Install fails or downloads slowly

Check that your network can reach the official install source, then review proxy, firewall, and DNS settings. On Windows, retry from an administrator terminal.

Command not found

Make sure Node.js, npm, and your global npm bin directory are on PATH. On macOS / Linux, check npm config get prefix. On Windows, reopen PowerShell or VS Code after changing environment variables.

Invalid key or 401

Check that the key was copied completely, has no extra spaces, and is not disabled or expired. The full key is only shown once after creation.

Wrong endpoint

Claude Code uses the selected hostname itself, such as https://www.aiplantform.site. OpenAI-compatible clients append /v1, such as https://www.aiplantform.site/v1. The US direct endpoint follows the same rule.

Long-running synchronous request times out

The standard endpoint passes through Cloudflare, so a long-running synchronous request may be subject to a proxy timeout. Change only the hostname to us.aiplantform.site, keeping the same protocol path and API key. The direct endpoint may be unreachable from some networks.

Environment variables did not apply

Temporary environment variables only apply to the current terminal. After editing ~/.zshrc, ~/.bashrc, or Windows user environment variables, reopen your terminal and editor.

Cannot connect to the API

Check the Base URL first, then review proxy, firewall, and DNS settings. On macOS / Linux, test both curl -I https://www.aiplantform.site and curl -I https://us.aiplantform.site. On Windows, use Test-NetConnection www.aiplantform.site -Port 443 and Test-NetConnection us.aiplantform.site -Port 443.

Balance or group mismatch

Confirm that your account has enough API Credits and that the key group matches the model. Image models need the image group and image endpoint.

Image API does not work

Image generation should use https://aigc.aiplantform.site, not the general OpenAI compatible endpoint. Also confirm that the key belongs to the media group.
