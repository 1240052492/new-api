# 隐私政策

**生效日期：2026 年 7 月 30 日**

> 本隐私政策说明你使用智算星球网站、控制台、API 网关、图片接口、文档和支持渠道时，智算星球运营方（以下简称“智算星球”或“我们”）如何收集、使用、披露和保护相关信息。

## 我们收集的信息

**账户与联系方式。** 我们可能收集用户名、邮箱、团队或公司名称、认证信息、客服联系方式，以及语言、主题等偏好设置。

**账单与交易信息。** 我们可能收集余额、充值、发票、支付状态、订单、退款、税务相关元数据。支付详情可能由支付服务商处理；我们不会有意保存完整银行卡号或支付密码。

**API 使用元数据。** 我们可能收集请求时间、接口、路由、模型、分组、状态码、延迟、Token 或图片用量、费用、密钥标识、工作区标识、错误类型以及类似运营元数据。

**技术数据。** 我们可能收集 IP 地址、浏览器类型、设备信息、操作系统、来源页面、访问页面、大致地区、日志和安全信号。

**支持沟通信息。** 如果你通过邮箱、表单或其他支持渠道联系我们，我们可能处理你提供的信息，以便回复并支持你的账户。

## API 内容与路由

API 请求可能包含提示词、消息、文件、图片、代码或其他内容。智算星球会为了路由请求、返回响应、排查问题、保护服务和履行适用义务而处理这些内容。

请求可能会根据你使用的路由、模型或分组传输给第三方模型或基础设施提供商。图片生成与编辑可能通过专用媒体端点处理，例如 `https://aigc.aiplantform.site`。

我们不会有意使用客户 API 输入或输出训练我们自己的模型。默认情况下，我们尽量不存储完整 API 请求和响应内容，除非你启用了相关存储功能、客服或调试需要、滥用或安全调查需要、法律合规要求，或服务中另有说明。

## 我们如何使用信息

我们使用信息来提供和运营服务、认证用户、创建和管理 API Key、路由模型请求、计算用量和账单、处理支持请求、通知服务变化、防止滥用、检测欺诈、保护系统、提升可靠性、分析聚合用量，以及履行法律义务。

## 我们如何披露信息

我们可能向模型提供商、托管服务商、支付处理方、安全与分析供应商、支持工具、专业顾问，以及帮助我们运营智算星球的其他服务提供商披露必要信息。

在法律要求、保护权利和安全、调查滥用或欺诈、合并收购等商业交易，或你指示我们向第三方共享信息时，我们也可能披露相关信息。

## 保留期限

我们会在提供服务、维护账户、支持账单、履行法律义务、解决争议、执行协议和防止滥用所需期间保留信息。具体保留期限取决于信息类型和处理原因。

API 使用元数据和安全日志可能会出于运营、计费和防滥用目的保留。账户和账单记录可能因会计、税务、合规或争议处理需要保留更长时间。

## 安全措施

我们采用技术和组织措施保护信息，包括传输中的 TLS 加密、访问控制、密钥处理实践、监控和内部最小权限访问。没有任何互联网服务可以保证绝对安全，因此你也应保护自己的账户、设备、API Key 和开发环境。

## Cookie 与本地存储

智算星球可能使用 Cookie、本地存储和类似技术处理登录、安全、主题、语言、会话状态、分析和产品偏好。你可以通过浏览器设置控制 Cookie，但禁用存储后部分功能可能无法正常工作。

## 你的选择与权利

根据你所在地区，你可能有权访问、更正、删除、导出或限制处理某些个人信息，也可能有权反对某些处理或退订营销信息。你可以通过下方列出的联系邮箱提出请求。

你也可以通过减少 API 提示词中的个人信息、轮换泄露密钥、删除未使用密钥、关闭未使用工作区，以及联系客服处理账户删除或账单问题，来减少我们处理的信息。

## 跨境处理

智算星球及我们的服务提供商可能在你所在国家或地区以外处理信息。这些地区的隐私法律可能不同。在法律要求时，我们会为跨境处理采用适当保障措施。

## 未成年人

服务不面向 13 岁以下儿童或适用法律规定的最低年龄以下用户。我们不会有意收集儿童个人信息。如果你认为儿童向我们提供了个人信息，请联系我们，我们会在适当情况下审查并删除。
